# CyanoB_Agg_Frag
This folder contains scripts for the investigation of aggregation/fragmentation of cyanobaterial colonies under strong shear, associated with the publication:
Yuri Z. Sinzato, Robert Uittenbogaard, Petra M. Visser, Jef Huisman, Maziyar Jalaal, 2025, Fragmentation and aggregation of cyanobacterial colonies, eLife 14:RP103503
https://doi.org/10.7554/eLife.103503.3

Two scripts are available:

•	CyanoB_Image_Analysis: This image processing routine detects colonies from images of a suspension of cyanobacteria under shear and calculates the statistical descriptors of the population over time.

•	CyanoB_Model: This routine simulates the time evolution of a caynobacteria suspension under aggregation/breakage
